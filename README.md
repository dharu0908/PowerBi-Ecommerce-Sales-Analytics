# E-commerce Sales Analytics Dashboard

Power BI dashboard analyzing e-commerce sales performance across India.

## Data

Two CSV files with 1,500+ transactions from 2018:

**Details.csv**
- Order ID, Amount, Profit, Quantity
- Category, Sub-Category, Payment Mode

**Orders.csv**  
- Order ID, Order Date, Customer Name
- State, City

## Metrics

- Revenue: 437.77K
- Profit: 36.96K
- Quantity: 5.62K units
- AOV: 120.90K

## Analysis

**Sales**
- Monthly profit tracking
- Payment modes: COD (46%), UPI (22%), Cards (24%), EMI (8%)
- Quarterly filters

**Geography**
- State-level profit (Madhya Pradesh, Maharashtra, UP, Gujarat, Tamil Nadu)
- Regional filters

**Products**
- Clothing: 63% of sales
- Furniture: 16%
- Electronics
- Top sub-categories: Printers, Bookcases, Sarees, Accessories, Tables

**Features**
- Interactive filters (time, region, category)
- Drill-down capabilities
